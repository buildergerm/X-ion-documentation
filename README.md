# Scrutium Documentation

Official product documentation for **Scrutium AI** — chat, research, and build with privacy by default. Built by **X-ion Team**.

## What this site covers

- Getting started & accounts
- Chat, models, tools, and thinking UI
- Projects & Build mode
- Library
- Memory across chats
- Age verification & parental controls
- Settings, privacy, and data controls
- Self-hosting for developers

## Stack

- Next.js 15
- MDX + Contentlayer
- Tailwind CSS 4

## Local development

```bash
pnpm install
pnpm dev
```

Documentation content lives in `/docs` as MDX. Navigation is configured in `config/sidebar.tsx`.

# Library

**Library** is a Grok-style hub for things you’ve created or attached in Scrutium.

## Open Library

Sidebar → **Library**.

## Tabs

- **All** — everything  
- **Media** — images and visual attachments  
- **Apps** — published apps from Build / projects  
- **Files** — other attachments  

## Grid

Items show a thumbnail when available, a title, and light metadata (relative time, size). Use the search field at the bottom to filter.

## Sources

Library aggregates:

- Chat attachments (Supabase storage)  
- Published apps (when present)  

Access is scoped to your user account via server APIs.

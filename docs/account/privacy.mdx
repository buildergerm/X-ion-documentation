# Privacy & data

## Private by default

Chats, attachments, memories, and preferences belong to your account. Server APIs authorize with Supabase auth and row-level policies.

## Cookies (desktop)

**Your privacy choices** opens the cookie preferences UI on **desktop**. Mobile focuses on core product chrome; the same policies still apply.

## Data controls

- Delete individual chats from history  
- **Delete all chats** under Data controls  
- Clear **Memory** separately under Settings → Memory  

## Guest usage

Guests are rate-limited by IP / guest id. Upgrade to a signed-in account for durable history and features.

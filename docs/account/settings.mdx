# Settings

Open Settings from the sidebar or account menu. The UI follows a mobile-first list of sections (Grok-style).

## Main sections

| Section | What it controls |
|---------|------------------|
| **Account** | Profile, sign-out related actions |
| **Appearance** | Theme, layout, interaction |
| **Personalization** | Length, creativity, language, tone, tools |
| **Memory** | On/off, list, add, delete, clear |
| **Privacy** | Privacy-related toggles |
| **Data controls** | Delete all chats, data notes |
| **Storage** | Cache |
| **Voice** | Tone presets |
| **Connections** | Connectors / developer tools |
| **About** | App name and version |

Search at the top of Settings filters section names.

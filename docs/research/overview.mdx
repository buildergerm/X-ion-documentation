# Research and information workflows

Use this guide to plan research tasks and work with AI-assisted information gathering. The tools available to you depend on the product, enabled capabilities, and current deployment.

## Start with a clear question

A useful research request explains:

1. **The question:** What are you trying to understand or decide?
2. **The scope:** Which dates, regions, subjects, or constraints matter?
3. **The evidence:** Which sources or documents should be considered?
4. **The output:** Do you need a summary, comparison, timeline, checklist, or detailed report?

## A practical workflow

1. Define the decision or question before collecting information.
2. Separate known facts from assumptions and open questions.
3. Ask for evidence, citations, or source details when the tool supports them.
4. Compare important claims against primary or authoritative sources.
5. Record uncertainty and information that could change the conclusion.
6. Save useful material in an appropriate project or library location if those features are available.

## Evaluate the result

AI-generated answers can be incomplete, outdated, or incorrect. For consequential decisions, verify important claims against reliable sources. Check dates, definitions, units, and whether the source actually supports the claim being made.

## Example prompt

```text
Research [topic] for [purpose].
Prioritize authoritative sources published within [date range].
Summarize the main findings, identify disagreements,
separate verified facts from assumptions, and list
the questions that still need investigation.
```

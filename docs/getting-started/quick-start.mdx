# Quick Start

## 1. Open Scrutium

Go to the live app (your deployed Scrutium URL). You’ll land on the guest or signed-in home with a simple prompt: **Ready when you are**.

## 2. Sign in (recommended)

Guests can try a limited number of messages. For full models, Projects, Memory, and Build mode, **sign in with email** (or your configured providers).

- Open **Sign in** from the header or sidebar.
- Use **email** for the full login flow (magic link / password as configured).
- Complete age verification if prompted (required before AI chat for new accounts).

## 3. Send a message

1. Type in the composer at the bottom.
2. Optionally pick an **action prompt** (Summary, Code, Design, Research, Learn).
3. Choose model speed (e.g. Fast) if available.
4. Send — you’ll see **Thinking for …** with live activity steps, then the answer.

## 4. Explore the sidebar

- **New chat** — start a fresh conversation  
- **Library** — media, files, and apps  
- **Projects** — group related chats and builds  
- **History** — past conversations  

## 5. Optional: turn on Memory

**Settings → Memory** — enable memory and add facts (or say “remember that…” in chat). Scrutium will use these in future conversations.

You’re ready. See [Chat overview](/docs/chat/overview) for deeper features.

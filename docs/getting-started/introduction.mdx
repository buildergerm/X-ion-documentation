## How to get started

1. Choose a product from the [product directory](/docs/products/overview).
2. Read its overview and follow the relevant quick-start instructions.
3. Check any account, role, permission, or provider requirements before connecting external services.
4. For technical configuration, use the [developer documentation](/docs/developers/environment).

## Documentation principles

- **Practical:** steps should be clear and actionable.
- **Accurate:** product and provider availability may depend on deployment, account permissions, and configuration.
- **Security-conscious:** never share API keys, access tokens, or other secrets in docs or support requests.

If a feature or integration is not visible in your product environment, verify that it is enabled for your account before assuming it is available.

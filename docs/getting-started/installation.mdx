# Installation

There are two codebases:

1. **Scrutium app** — the AI product users chat with  
2. **Scrutium documentation** — this MDX docs site  

## Documentation site (this repo)

```sh
git clone https://github.com/buildergerm/scrutium-documentation.git
cd scrutium-documentation
pnpm install
pnpm dev
```

Open the local URL Next.js prints (usually `http://localhost:3000`). Edit MDX under `/docs` and navigation in `config/sidebar.tsx`.

## Scrutium app

```sh
git clone https://github.com/buildergerm/scrutium-artificial-Intelligence.git
cd scrutium-artificial-Intelligence
npm install
# configure .env.local with Supabase + model keys
npm run dev
```

See [Self-hosting](/docs/developers/self-hosting) and [Environment variables](/docs/developers/environment) for production setup.

## End users

You do **not** need to install anything to use Scrutium. Open the deployed app, sign in, and start chatting — [Quick Start](/docs/getting-started/quick-start).

## How to use this documentation

1. Select the product you want to use.
2. Start with its overview or quick-start guide.
3. Follow the feature or integration guide for the task you want to complete.
4. Check prerequisites and permissions before connecting external services.

## Accuracy and availability

Features, integration options, and permissions may vary by product version, deployment, account, and third-party provider. Guides should call out any setup requirements and should not imply that a provider connection is available until it has been configured and verified.

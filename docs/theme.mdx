# Theme

Scrutium supports **system**, **light**, and **dark** themes.

Change appearance under **Settings → Appearance**. Preferences sync for signed-in users.

For full settings documentation, see [Settings](/docs/account/settings) and [Preferences](/docs/personalization/preferences).

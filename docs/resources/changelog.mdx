# Product updates

This page is the home for product updates and release notes across the X-ion ecosystem. Add an entry when a release has been verified and its changes are ready to communicate.

## What a release note should include

Each update should make clear:

- **Release date:** When the change became available.
- **Product:** Which product or component changed.
- **Summary:** What changed, in plain language.
- **Impact:** Who may notice the change and what it means for their workflow.
- **Action required:** Whether users need to do anything.
- **Availability:** Any relevant rollout, account, or deployment limitations.

## Writing accurate updates

Distinguish between shipped changes, previews, planned work, and known issues. Do not describe a planned feature as available until it has been released and verified. If a change may cause temporary service interruption, state the affected service and confirmed maintenance window.

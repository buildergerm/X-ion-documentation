# Environment variables

Exact names may vary by version; treat this as a checklist. Production deployments talk to **X-ion servers** for auth, data, and models.

## X-ion backend (core)

- Public project URL (client)  
- Public anon / publishable key (client)  
- Service role / server key (server only — never expose to the browser)  

## Models (X-ion)

- X-ion model API key(s) and base URL as required by your deployment’s model map  
- Default model id (e.g. the Fast / default profile shown in the composer)  

## Search & live tools

- Web search provider key if enabled for research tools  
- Live weather / places / crypto often use public endpoints; no key required for basic setups  

## Optional

- Analytics, email, and connector secrets as you enable features  

Never commit secrets. Use your host’s env UI or a secrets manager.

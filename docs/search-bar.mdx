# Search

## In the app

- **Chat history** — filter conversations from the sidebar / history UI  
- **Library** — search field filters media, files, and apps  
- **Settings** — search filters setting section names  

## On this documentation site

Use the docs search control in the header to jump between product pages (Getting Started, Chat, Memory, Developers, and more).

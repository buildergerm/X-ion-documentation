# Preferences

Scrutium stores preferences per user (and sensible defaults for guests).

## Common options

- **Theme** — system / light / dark  
- **Layout** — sidebar vs fullscreen  
- **Response length** — short / medium / detailed  
- **Creativity** — 0–100  
- **Language & voice tone**  
- **Web search & image generation** toggles  
- **Default model**  
- **Prompt suggestions**, tool invocation visibility, conversation previews  

Changes apply to subsequent chat requests via the personalization payload and system prompt.

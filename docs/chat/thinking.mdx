# Thinking & activity

While Scrutium works, the message area shows a **thinking panel** similar to modern AI products:

## Header

- **Thinking for 12s** — live elapsed time while streaming  
- **Thought for 24s** — after completion, when reasoning is available  

Click the header to expand or collapse details.

## Activity steps

Examples of steps you may see:

- Understanding your request  
- Searching the web… / Used webSearch  
- Writing code…  
- Updating memory…  
- Composing the response…  

Each step has a status: pending, active (spinner), or done.

## Reasoning

If the model streams reasoning content, it appears under the thought header so you can audit how the answer was formed without cluttering the main reply.

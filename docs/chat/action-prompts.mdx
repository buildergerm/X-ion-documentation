# Action prompts

Above the chat input, Scrutium shows short **action prompts** that bias the next message toward a task type:

- **Summary** — condense text or ideas  
- **Code** — programming help  
- **Design** — UI/UX and visual structure  
- **Research** — deeper investigation  
- **Learn** — explanations and teaching  

They are arranged to **wrap on mobile** so every option stays visible without horizontal scrolling.

Tap a prompt, then type your question — or type freely without selecting one.

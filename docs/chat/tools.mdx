# Tools & live data

When tools are enabled (signed-in, non–Build mode), Scrutium can call structured tools instead of inventing live numbers.

## Available tools (typical deployment)

| Tool | Purpose |
|------|--------|
| **webSearch** | Current events and research |
| **getWeather** | Live weather for a place |
| **searchPlaces** | Real places / addresses |
| **getCrypto** | Live crypto prices |
| **getFx** | Currency conversion |
| **getWorldTime** | Local time for a city or zone |
| **getWiki** | Wikipedia summary |
| **remember** | Save a durable memory fact |

## How it looks

Tool calls appear as compact rows (name, status Running / Done). Expand a row to see query and results. The thinking panel may list **Using webSearch…** style steps while work is in progress.

## Web search toggle

You can disable web-related tools from preferences if you prefer offline-style answers only.

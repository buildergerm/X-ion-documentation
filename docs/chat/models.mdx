# Models & speed

Scrutium can expose multiple models. Guests are limited to a safe default set; signed-in users can access the full list configured for your deployment.

## Speed / model control

Use the control near the composer (e.g. **Fast**) to pick a model or latency profile. Your default model can be set in **Settings** preferences.

## Response style

Under **Personalization** you can set:

- Response length — short / medium / detailed  
- Creativity level  
- Language preference  
- Voice / tone  

These are injected into the system prompt at request time so answers match your preferences.

## Limits

Daily message quotas apply for free and guest usage. Rate limits return a clear retry message when exceeded.

# Chat overview

Scrutium chat is built for clarity: a clean empty state, streaming answers, visible thinking, and optional tools.

## Empty state

New chats show a simple line — **Ready when you are** — without heavy marketing copy or large logos in the message area.

## Composer

- Text field: “Ask anything”  
- Attachments via **+** (where enabled)  
- Model / speed control (e.g. Fast)  
- Action prompts above the input: Summary, Code, Design, Research, Learn  

On mobile, action prompts wrap so nothing is hidden behind horizontal scroll.

## Messages

- User messages appear on the right  
- Assistant messages stream in with optional **reasoning** and **tool** rows  
- Follow-up suggestions with arrow icons can appear under the last assistant reply  

## Modes

Header tabs may include **Ask**, **Imagine**, and **Build** depending on your deployment. Build mode is for generating app/page code and is restricted to signed-in users.

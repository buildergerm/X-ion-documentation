# Projects

**Projects** group related conversations and build work so you can leave a topic and return with context.

## Open Projects

From the sidebar, open **Projects**. You’ll see a list of your projects and can create a new one.

## Project chats

Each project has its **own chats**. Opening a project shows only conversations linked to that project (`project_id`), not your entire history.

- Create a chat from inside a project so it stays associated  
- Titles and activity update like normal chats  

## Tips

- Name projects by goal (“Marketing site”, “API redesign”)  
- Use Build mode inside a project when generating apps  
- Pin important chats if your deployment supports pinning

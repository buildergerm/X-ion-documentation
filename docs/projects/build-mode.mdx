# Build mode

**Build** is for generating HTML/apps and iterative product UI — not general chat.

## Requirements

- Signed-in account  
- Age eligibility  
- Guest users cannot use Build  

## How to use

1. Select **Build** from the header (or start a build-oriented prompt)  
2. Describe the page or app you want  
3. Scrutium streams structured output (often with file paths such as `index.html`)  
4. Iterate with follow-ups (“make the hero darker”, “add a pricing section”)  

## Projects + Build

Keep long-running product work inside a **Project** so related chats stay together. Published apps can appear in **Library** when publishing is enabled.

## Limits

Build responses may allow higher token limits than normal chat. Tool-heavy web search is typically disabled in pure Build mode so the model focuses on code.

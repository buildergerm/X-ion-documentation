# X-ion Organization

**X-ion** builds a growing family of digital products. X-ion Docs is the shared documentation hub for product guides, integration instructions, and developer resources.

## Product ecosystem

### Scrutium AI

Scrutium AI is an AI workspace for chat, research, and building. Its documentation covers conversations, available tools, Projects, Build mode, Library, Memory, personalization, account controls, privacy, and developer setup.

[Read the Scrutium AI documentation](/docs/products/scrutium-ai)

### Draft

Draft supports campaign and content workflows and connects with external services for publishing, commerce, collaboration, and analytics. Connection availability and permissions depend on each provider and the Draft deployment configuration.

[Read the Draft documentation](/docs/products/draft)

## Documentation principles

- **Product-specific:** explain where a feature lives and how to use it.
- **Practical:** include prerequisites, setup steps, and troubleshooting.
- **Transparent:** distinguish generally available functionality from features that require provider access or configuration.
- **Secure:** never include real API keys, access tokens, or private customer information in documentation.

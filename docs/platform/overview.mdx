# Platform overview

X-ion documentation brings product guidance, setup instructions, workflows, and developer resources into one place. Use this overview to understand where to start and how to find the information relevant to your work.

## Product areas

### Scrutium AI

Scrutium AI is an AI workspace. Its documentation covers conversations, prompting, supported tools, project organization, the Library, Memory, personalization, account settings, and developer configuration.

[Explore Scrutium AI](/docs/products/scrutium-ai)

### Draft

Draft supports campaign and content workflows. Its guides explain the product's workflow and how to evaluate, configure, and troubleshoot supported integrations.

[Explore Draft](/docs/products/draft)

### Developer resources

Developer documentation covers environment configuration, integration planning, API setup, and deployment considerations. API details should be taken from the live API Console or the relevant verified service specification.

[Explore developer resources](/docs/developers/environment)

## How the ecosystem fits together

- **Products** describe the user-facing tools and their supported workflows.
- **Guides** explain how to complete tasks step by step.
- **Integrations** describe the prerequisites for connecting external providers.
- **Developer resources** cover configuration, implementation, and operational concerns.
- **Policies and security guidance** help users understand responsible account and credential handling.

## Availability and version differences

Features may differ by product, account permissions, deployment, region, or third-party provider. Confirm that a feature is available in your environment before designing a workflow around it. Documentation should distinguish verified behavior from examples and recommendations.
